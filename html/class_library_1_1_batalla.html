◆ EsMiTurno()

bool Library.Batalla.EsMiTurno ( ComponentInteractionCreateEventArgs args)
inline

Verifica si es el turno del jugador que realizó la interacción en Discord.

Parameters
argsArgumentos del evento de interacción del componente, que contienen información sobre el usuario y el canal.
Returns
Devuelve true si es el turno del jugador correspondiente, de lo contrario, devuelve false y envía un mensaje indicando que no es el turno actual del usuario.

Este método compara el nombre del jugador activo con el nombre del usuario que realizó la interacción. Si no es el turno del jugador, envía un mensaje informativo al canal correspondiente.

Ejemplo de uso:

if (batalla.EsMiTurno(args))
{
// Ejecutar acciones del jugador
}

◆ Iniciar_Batalla_Pruebas()

async Task Library.Batalla.Iniciar_Batalla_Pruebas ( ComponentInteractionCreateEventArgs ctx)
inline

Inicia una batalla de prueba entre dos jugadores, utilizando el primer Pokémon de cada jugador.

Parameters
ctxContexto del evento de interacción del componente, necesario para modificar el mensaje en Discord.

Este método selecciona automáticamente el primer Pokémon de cada jugador para la batalla. Se determina aleatoriamente quién comienza el turno. Luego, se construye un mensaje con opciones de acción (atacar, usar mochila, cambiar Pokémon) que se envía al canal de Discord correspondiente.

Returns
Una tarea asincrónica que representa la operación de modificar el mensaje en Discord para la interacción.

Ejemplo de uso:

await batalla.Iniciar_Batalla_Pruebas(ctx);

inline

Alterna el turno entre los jugadores y ejecuta las acciones correspondientes del jugador activo en la batalla.

Parameters
ctxContexto del evento de interacción del componente, utilizado para realizar acciones y modificar mensajes en Discord.

Este método determina de quién es el turno actualmente (jugador 1 o jugador 2), ejecuta las acciones del jugador activo y actualiza los enfriamientos de los ataques especiales del jugador correspondiente.

Returns
Una tarea asincrónica que representa las acciones realizadas por el jugador activo durante su turno.

Ejemplo de uso:
