async Task Library.Facada.IniciarBatalla ( string nombreJugador,
InteractionContext ctx )
inline

Inicia una batalla entre dos jugadores seleccionados de la sala de espera.

Parameters
nombreJugadorEl nombre del jugador que solicita iniciar la batalla.
ctxEl contexto de la interacción en Discord.
Returns
Una tarea asíncrona que representa la operación de iniciar la batalla.

Este método verifica que ambos jugadores tengan al menos 6 Pokémon seleccionados. Si alguno de los jugadores no cumple con este requisito, se envía un mensaje al canal de Discord indicando que deben seleccionar más Pokémon. Si ambos jugadores cumplen, se crea una instancia de la clase Batalla para gestionar el combate.

Exceptions
ExceptionLanza una excepción si ocurre un error durante el manejo de la interacción de Discord.

Ejemplo de uso:

await IniciarBatalla("Jugador1", ctx);

string Library.Facada.MostrarPokemonsDisponibles ( string nombreJugador)
inline

Muestra todos los Pokémon disponibles en el juego para un jugador específico.

Parameters
nombreJugadorEl nombre del jugador que solicita ver los Pokémon disponibles.
Returns
Una cadena con la lista de todos los Pokémon disponibles en el juego si el jugador está en la sala de espera. Si el jugador no está en la sala de espera, devuelve un mensaje indicando que debe unirse primero.

Este método verifica si el jugador está en la sala de espera utilizando el método SalaDeEspera.ObtenerJugador. Si el jugador es encontrado, llama al método Jugador.Mostrar_Todos_Los_Pokemons_Disponibles_Del_Juego para obtener la lista completa de Pokémon. En caso contrario, sugiere unirse al juego.

Ejemplo de uso:

string pokemons = MostrarPokemonsDisponibles("Jugador1");
Console.WriteLine(pokemons);

string Library.Facada.MostrarPokemonsDisponiblesDelJugador ( string nombreJugador)
inline

Muestra los Pokémon disponibles de un jugador específico en la sala de espera.

Parameters
nombreJugadorEl nombre del jugador cuyos Pokémon disponibles se desean mostrar.
Returns
Una cadena con la lista de Pokémon disponibles del jugador si se encuentra en la sala de espera. Si el jugador no se encuentra, devuelve un mensaje indicando que no fue encontrado.

Este método busca al jugador en la sala de espera y, si lo encuentra, llama al método Jugador.Mostrar_Pokemons_Disponibles_Del_Jugador para obtener la lista de sus Pokémon. Si el jugador no está en la sala de espera, devuelve un mensaje de error.

Ejemplo de uso:

string pokemons = MostrarPokemonsDisponiblesDelJugador("Jugador1");
Console.WriteLine(pokemons);
